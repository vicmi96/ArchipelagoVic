# Git: ignore dist and node_modules

**Date:** 2026-10-19 19:15 (local time)
**Request:** "Can we add the dist folder to the git ignore, it's over 100mb and it wont accept the commit"

## What changed

**New `.gitignore`** in the project root, with these entries:
- `dist/`: the installer, portable exe and unpacked app made by `Build installer.cmd`. The Setup and portable exes are about 111 MB each, and `win-unpacked\ArchipelagoVic.exe` is 246 MB. GitHub refuses any file over 100 MB.
- `node_modules/`: Electron and npm's other downloads. `node_modules\electron\dist\electron.exe` alone is 246 MB, so it would be refused too. Anyone who clones the project gets it again with `npm install` or by running `Start ArchipelagoVic.cmd`.
- Clutter: `Thumbs.db`, `desktop.ini`, `.DS_Store`, `*.log`.

## Why the ignore file alone isn't enough

The "Initial commit" already contains both folders:
- 78 files under `dist/`;
- 563 files under `node_modules/`.

An ignore file only affects files that aren't committed yet, so they have to be taken out of that commit. Your copies on disk are not deleted. Run these in the project folder:

```
git rm -r --cached dist node_modules
git add .gitignore
git commit --amend -m "Initial commit"
git push -u origin main
```

`--amend` rewrites the commit. That's safe here because the push was rejected, so nothing is on GitHub yet.

## Sharing the installer

To share the installer, create a GitHub Release and attach `dist\ArchipelagoVic Setup 2.3.1.exe` to it. Release files can be up to 2 GB.
