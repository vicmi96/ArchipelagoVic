## New files
- `package.json`: the Electron app. `npm start` runs it, `npm run dist` builds an installer, and `npm run standalone` rebuilds the browser-only client. Electron is pinned to 44.4.5.
- `Start ArchipelagoVic.cmd`: double-click to run. On the first run it installs Electron (it needs Node.js LTS).
- `main.js`: the main process.
  - Finds your Archipelago install by checking these places in order:
    1. `APVIC_AP_PATH`
    2. the saved choice
    3. `C:\ProgramData\Archipelago`
    4. Program Files
    5. LocalAppData
  - Launches components:
    - directly through their own `.exe` where one exists;
    - otherwise through `ArchipelagoLauncher.exe "<Component name>"`, the official CLI;
    - patch files and `.apworld` files go through `ArchipelagoLauncher.exe <file>`.
  - Runs `ArchipelagoServer.exe` and `ArchipelagoGenerate.exe` with live output and server stdin.
  - Manages the Players folder, Templates, custom_worlds, output and host.yaml. It only touches files inside the Archipelago folder, and removals go to the Recycle Bin.
  - Asks before quitting while a server is running.
- `preload.js`: a narrow bridge with a fixed list of actions (context isolation and sandbox on, no Node in the page).
- `components.json`: all 39 user-facing Launcher components for Archipelago 0.6.8, taken from the 0.6.8 source: name, type, executable, description and file types.
- `renderer/index.html`, `styles.css`, `client.js`, `launcher.js`: the interface. The page has a strict Content Security Policy.
- `tools/build-standalone.js`: inlines `renderer/` into `ArchipelagoClient.html`.
- `README.md`: how to run it and what's where.

## Changed
- `ArchipelagoClient.html` is now generated from `renderer/`. It's the text client as one file for any browser, with everything below except the launcher sections.

## Launcher: every Archipelago Launcher function
- **Home:** Join, Host, Generate, Open patch, Start a game client. Also recent rooms (with Join), what's running now, and the website/Discord/After Dark links.
- **Host (built in):**
  - Choose a multiworld from `output` or browse for one.
  - Port, room password, admin password and hint cost.
  - Under "More server rules": release/collect/remaining modes, hint points per check, auto-stop and turning off !getitem.
  - Live console with "Who's connected", "Progress", "Save now" and "All commands", plus free command entry.
  - "Join this game" fills in `localhost:<port>` in Play.
  - Your settings are remembered.
- **Generate (built in):**
  - Players table showing slot name, game, file, Edit (in-app editor with a `.bak` backup) and Remove.
  - Add YAMLs by file picker or drag and drop.
  - Templates: "Create templates" runs Generate Template Options. Choose a game, give it a slot name, and it's copied into Players and opened for editing.
  - Seed, spoiler level, race mode and skip progression balancing.
  - Live generator output. On success: "Host this game" and "Open output folder". On failure: a plain explanation.
- **Worlds:** installed `.apworld` list. Install through the official installer by button or drag and drop. Remove sends the file to the Recycle Bin. Build APWorlds, Export Datapackage and Generate Template Options are here too.
- **Clients & tools:** every client, tool and adjuster grouped and searchable, with the file types each opens. "Start" opens the official program. A free-text box starts any component an installed `.apworld` adds.
- **Settings:** Archipelago folder (Change, Browse files, Open logs, Options Creator); a host.yaml editor (Save with `.bak`, Revert, Open in editor); Alerts, Theme and Color guide.
- **Status in the side rail:** shows when the server is live, generation is working, or you're connected in Play.

## Text client improvements (all five from the list)
1. **Alerts.** A sound (a short chime, different for traps) plus a desktop notification and taskbar flash when the window isn't focused. Choose which events trigger them:
   - you receive a key item (on by default);
   - you receive any item;
   - a hint about your item (on);
   - your name is mentioned in chat (on);
   - a player reaches their goal.

   Settings are in Play → Alerts or Settings, with a "Try it" button.
2. **"Key items still out there."** A header stat counting hinted key items you haven't received. The tooltip lists where they are, and clicking it opens Hints.
3. **History that survives restarts.** The activity log is saved per room, team and slot (the last 2,000 events and the 12 most recent rooms). When you reconnect it comes back above an "Earlier sessions above" divider. `/clear` also wipes the saved history.
4. **Game categories.** Received → "Group by category" and Checks left → "Group by area" use the game's own item and location groups from the server. Each item goes in its most specific group, and "Other" comes last. The toggle is greyed out with an explanation for games that define no groups.
5. **Quick command buttons:**
   - "Ask for a hint…"
   - "Items left in my world" (`!remaining`)
   - "Everyone's progress" (`!status`)
   - "Collect"
   - "Release"

   Collect and Release ask for confirmation. Buttons the room doesn't allow are greyed out with the reason, e.g. "allowed only after you reach your goal".
