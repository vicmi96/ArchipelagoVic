# ArchipelagoVic 2.9.0: Home shows what's happening first

**Date:** 2026-10-21 09:45 (local time)
**Request:** "I want to redesign the home page", then "Build direction A (Status first)", picked from the design canvas.

## What changed

**Home now opens with "Right now": three cards for your rooms, the server and updates.**
- **Rooms:** "1 room connected" with each connected room (up to 3) and an Open button. Otherwise it says "No room connected" and offers **Join a game**.
- **Server:** "Server running" with the port and **Open server**, or "Generating" with **Open generator**. Otherwise it says "Server off" and offers **Host a game** (disabled without an Archipelago install).
- **Updates:** a title that says when updates are available ("2 updates available"). Below it: each update with its button, then any note about why something couldn't be checked, for example "No ArchipelagoVic release is published on GitHub yet…" (still never hidden), the versions, and **Check now** with the time of the last check.

**The six tasks are now tiles** (icon, name, one line) in a grid of up to three columns. Join a game is highlighted. The wording and destinations are unchanged.

**Recent rooms is a single list** with each room's game, address and Join. A room you're already in says **Connected** and offers **Open** instead.

**Community links** moved to a footer line.

**Grey text is darker in the light Archipelago theme** (`--ink-3` #73868B → #5E7076), so small grey text is easier to read on the page background. The other themes keep their own colours.

**The page title** is now "Home" instead of "What do you want to do?", with the Archipelago version and folder on the right.

## Files

- **`renderer/index.html`:** the new Home markup.
- **`renderer/styles.css`:** Home styles replace the old task list and two-column layout; the darker `--ink-3`.
- **`renderer/themes.js`:** the Archipelago theme card preview uses the new grey.
- **`renderer/launcher.js`:** `renderHome` fills the Rooms and Server cards and the recent list; `renderUpdates` fills the Updates card; new helper `nowCard`.
- **`README.md`:** the Home row in "Using it".
- **`package.json`:** 2.9.0.

## Tested

In a test window started from this folder with its own settings folder (`--user-data-dir`), checked with screenshots:
- **Light theme, nothing running:** "No room connected", "Server off", "Everything is up to date"; tiles 3 × 2; example recent rooms with Join.
- **Dark theme, a room connected and the server running** (faked in the page): "1 room connected" with Open, "Server running" on port 38281 with Open server, and the matching recent room says Connected with Open.
- **Updates card** (faked): with the no-release note it reads "Archipelago and your worlds are up to date." then the note; with updates it reads "2 updates available" with Update… and Update.
- No horizontal scrolling at a 1304 px wide window.

`node --check` passes for `renderer/launcher.js` and `renderer/themes.js`. The test settings folder is in a temporary folder, not in the project.

**Not tested:** a real room connection and a real server (both were faked in the page), the narrow-window layout (under 900 px), and the built installer.
