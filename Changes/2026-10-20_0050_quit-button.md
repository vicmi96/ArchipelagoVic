# ArchipelagoVic 2.7.0: Quit button

**Date:** 2026-10-20 00:50 (local time)
**Request:** "Add a button on the app to Quit, since the normal button to close the window adds it to the tray, the app should have a Quit button"

## What's new

- **Quit button** at the bottom of the sidebar. It works with every theme: with a theme picture it sits under the picture and the version line, and in a narrow window it shrinks with the rest of the sidebar.
- **Ctrl+Q** does the same from anywhere in the window, including while typing in a room tab.
- **It asks first only when something would be cut off.**
  - With nothing connected, it quits straight away.
  - With a connected room or a server you're hosting, it asks once, in one "Quit ArchipelagoVic?" box. For example: "The server you're hosting stops and everyone is disconnected. Progress is saved. You leave your room. It opens again the next time you start ArchipelagoVic. Games you started from Games keep running."
  - The button says "Stop server and quit" when a server is running, otherwise "Quit".
  - The server question used to be a separate Windows dialog when quitting. It isn't asked a second time after this box.
- **Closing the window still only hides ArchipelagoVic in the tray,** as before. The one-time tray balloon now also mentions the Quit button.

## Files

- **`main.js`:**
  - IPC `app:quit`, which quits through the existing `quitApp()`. When the window already asked, it skips the server question.
  - Ctrl+Q through `before-input-event`, so it also works while a room tab (iframe) has focus. It sends `app:quitAsk` to the window.
  - The tray balloon text mentions Quit.
- **`preload.js`:** `quit` and `onQuitAsk`.
- **`renderer/index.html`:** the Quit button in the sidebar, with a tooltip.
- **`renderer/launcher.js`:** `quitArchipelagoVic` (the confirmation text), plus wiring for the button and the shortcut.
- **`renderer/styles.css`:** `.rail-quit`. It uses existing tokens only; on hover it tints with `--bad`. There are rules for the theme picture and the narrow sidebar.
- **`README.md`:** a Quit line under "Several rooms, and staying out of the way".
- **`package.json`:** 2.7.0.
- **`ArchipelagoClient.html`:** rebuilt (`styles.css` changed).

**Mistakes in my own test runs (not app problems):**
- **The window-close test.** My first version closed the window with the page's own `window.close()`, which quit the app. That isn't what the ✕ button does, so it was redone with a real window close.
- **The first Ctrl+Q test.** It sent the key without the Windows key code a real keyboard includes, so the shortcut wasn't recognised. It was redone with a full key event.
